# 👗 Edge Fashion Analysis Dashboard

An interactive **Fashion Analysis Dashboard** built using Python and Streamlit to explore and analyze different fashion product categories through a user-friendly interface.

🔗 **Live Dashboard:** [Edge Fashion Analysis](https://edge-fashion-analysis.streamlit.app/)

## 📌 Project Overview

The Edge Fashion Analysis Dashboard provides a visual way to explore fashion categories and gain insights into the fashion domain. It demonstrates how Python-based data applications can make information easier to understand through interactive dashboards and visualizations.

## ✨ Key Features

- 👗 **Fashion Category Analysis** — Explore different fashion categories, including Lehengas, Saree Sets, Anarkalis, Sharara, Kurtas, Peplum, Co-ord Sets, and Jackets.
- 📊 **Data Visualization** — Present fashion-related information in a visual and easy-to-understand format.
- 🔎 **Interactive Exploration** — Explore the available dashboard features to understand the fashion data.
- 💻 **User-Friendly Interface** — Access fashion analysis through a simple web-based dashboard.
- 📈 **Data-Driven Insights** — Use visual analysis to support better understanding of fashion categories.

## 🛠️ Technologies Used

- **Python** — Core programming language
- **Streamlit** — Interactive dashboard development
- **Pandas** — Data manipulation and analysis
- **Data Visualization** — Visual representation of fashion-related information
